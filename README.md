# Análise Exploratória de Acidentes de Trabalho na Construção Civil utilizando dados da CAT/INSS

## 📌 Sobre o projeto

Este projeto foi desenvolvido como uma prática dos conhecimentos adquiridos em um minicurso de **R e Análise de Dados**, com o objetivo de aplicar conceitos de manipulação de dados, estatística descritiva e visualização de informações.

Trata-se de um projeto introdutório, desenvolvido por uma estudante em fase inicial de aprendizado na área de dados, buscando explorar a linguagem **R** e compreender melhor o processo de tratamento, análise e interpretação de uma base de dados real.

A análise utiliza registros de **Comunicação de Acidente de Trabalho (CAT)** disponibilizados pelo **Instituto Nacional do Seguro Social (INSS)**, tendo como recorte os acidentes de trabalho ocorridos no setor da **construção civil durante o mês de maio de 2026**.

O objetivo não é realizar uma análise definitiva sobre a segurança do trabalho no setor, mas sim aplicar na prática técnicas de análise exploratória de dados, identificando padrões e informações relevantes presentes na base.

---

## 🎯 Objetivos do projeto

Este projeto busca praticar e desenvolver habilidades relacionadas a:

* Importação e organização de dados;
* Limpeza e transformação de informações;
* Manipulação de dados utilizando R;
* Criação de visualizações com `ggplot2`;
* Aplicação de estatística descritiva;
* Exploração de relações entre variáveis categóricas.

---

## 📊 Perguntas exploradas na análise

Durante o desenvolvimento do projeto, foram investigadas questões como:

* Quais estados apresentaram maior quantidade de registros de acidentes?
* Quais ocupações da construção civil tiveram maior número de ocorrências?
* Como os acidentes estão distribuídos entre estados e profissões?

---

## 📈 Visualizações desenvolvidas

Foram utilizadas diferentes técnicas de visualização para explorar os dados:

* Gráficos de barras para comparação entre categorias;
* Heatmaps para análise da relação entre estado e ocupação;
* Gráficos de proporção para análise de acidentes com óbito;
* Visualizações temporais para observar a distribuição dos registros durante maio de 2026.
